# CT Vai na Fita

Landing page mobile-first para captação e agendamento de aulas experimentais
de futevôlei do CT Vai na Fita, em Icaraí, Niterói.

## Recursos

- apresentação da aula experimental gratuita;
- seleção de dia e horário;
- localização oficial com mapa e acesso à rota;
- contato direto pelo WhatsApp;
- layout responsivo para acesso por QR Code;
- deploy compatível com Vercel.

## Desenvolvimento

Requer Node.js 22 ou superior.

```bash
npm install
npm run dev
```

Para validar a versão destinada ao Vercel:

```bash
npm run vercel-build
```
